# Calculator

Консольный калькулятор на Java: операции `+`, `-`, `*`, `/`, результат становится первым операндом следующей операции.

Команды (без учёта регистра): `C` — сброс результата, `S` — завершение работы.

```bash
./gradlew installDist && build/install/calculator/bin/calculator
```

```bash
./gradlew test
```
